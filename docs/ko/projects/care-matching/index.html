환자와 간병인을 위한 맞춤형 정보 제공

2022년 9월~2023년 1월 · 연구보조원, 한국연구재단

환자와 간병인을 연결하는 모델 개발에 참여했습니다. 팀은 환자·간병인 프로필, 위치, 과거 만족도를 활용해 적합한 간병인을 추천하도록 모델을 설계했습니다. 관련 등록 특허의 공동 발명자입니다.

특허 정보

매칭 연구와 특허 등록

한국연구재단의 환자–간병인 매칭 연구에 연구보조원으로 참여했습니다. 연구 결과를 담은 국내 특허 10-2635315에 공동 발명자로 등재됐습니다.

간병인 후보를 찾는 데 쓴 정보

환자와 간병인의 기본 정보, 위치 등을 먼저 확인해 매칭 후보를 좁힙니다. 이전 간병 서비스의 만족도 자료로 모델을 학습시켜, 후보와 환자가 짝을 이뤘을 때의 만족도를 추정합니다.

추정치를 어디에 쓰는지

예상 만족도는 후보를 추천 순서로 정리하는 데 씁니다. 그림은 위치 조건을 확인해 후보를 찾는 단계부터 추천 결과를 내는 단계까지를 보여 줍니다.
