이차전지 양극재의 금속 이물 검출

2025년 1~5월 · 연구원, 에코프로비엠

공정 센서 측정값과 금속 이물 검사 결과를 분석했습니다. 두 데이터를 생산 로트 기준으로 연결해 검출 모델의 학습 데이터를 구성하는 방법을 검토했습니다.

센서값과 검사 결과를 연결하는 일

양극재를 만드는 동안 얻는 센서값과 실험실의 금속 성분 검사 결과는 따로 쌓입니다. 어떤 공정 센서값이 어느 검사 결과에 해당하는지 생산 로트 단위로 확인해 학습용 데이터를 구성했습니다.

가상 계측 모델

공정 변수끼리의 상호작용과 시간에 따른 변화를 나타내는 특성을 만들고 모델 학습에 사용했습니다. QCP 공정 측정값으로 ICP 검사에서 나올 금속 성분 농도를 예측해, 실험실 결과가 나오기 전에 이물 위험을 살필 수 있는지 검토했습니다.

설비 쪽에서 맡은 일

금속 이물 예측과 별도로 설비 상태 지표(Health Index) 설계에 참여했습니다. 지표가 시간에 따라 변하는 모습을 살폈습니다. 그 신호로 설비 이상을 미리 알 수 있을지 평가하는 기준도 만들었습니다.
