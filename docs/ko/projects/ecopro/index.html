이차전지 양극재의 금속 이물 검출

2025년 1~5월 · 연구원, 에코프로비엠

시간별 센서 기록과 로트별 검사 결과

공정 센서값은 시간순으로 쌓이고 ICP 검사 결과는 생산 로트별로 나옵니다. 검사한 로트의 생산 시간대를 찾아 그때 기록된 센서값과 검사 결과를 짝지어 학습 데이터를 만들었습니다.

QCP 센서값으로 ICP 농도 추정

센서값의 시간 변화와 공정 변수 사이의 상호작용을 가상 계측 모델의 입력에 반영했습니다. 이 모델은 QCP 센서값으로 ICP에서 재는 금속 농도를 추정합니다. 추정값은 이물이 나온 공정을 조사하는 데 참고할 수 있습니다.

설비 상태 지표

설비 상태 지표(Health Index)를 설계하는 데도 참여했습니다. 센서값으로 설비 상태 변화를 미리 판단할 수 있는지 확인할 기준을 함께 정했습니다.
