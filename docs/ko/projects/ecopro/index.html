이차전지 양극재의 금속 이물 검출

2025년 1~5월 · 연구원, 에코프로비엠

센서 기록과 검사 결과를 로트로 연결

공정 센서는 시각마다 값을 남기고 실험실의 ICP 검사 결과는 생산 로트별로 정리됩니다. 이 자료를 학습에 쓰려면 어느 구간의 센서값이 검사한 로트에 해당하는지부터 맞춰야 합니다. 생산 로트를 기준으로 센서값과 검사 결과를 짝지었습니다.

공정에서 잰 값으로 검사 결과를 추정했습니다

가상 계측 모델에 넣을 특성을 만들 때 센서값이 시간에 따라 어떻게 변하는지와 공정 변수끼리 함께 움직이는 양상을 살폈습니다. 모델은 QCP 공정 센서값으로 ICP에서 측정하는 금속 농도를 추정합니다. 추정치는 금속 이물이 어느 공정에서 생겼는지 조사할 때 참고할 수 있도록 설계했습니다.

설비의 상태를 나타내는 지표

금속 농도 추정과 별도로 설비 상태 지표(Health Index) 설계에도 참여했습니다. 지표가 시간에 따라 어떻게 변하는지 살폈습니다. 설비 상태가 달라지기 얼마나 전에 센서 신호가 바뀌는지 판단할 기준을 정했습니다.
