압연 데이터를 다루는 선형회귀 과제

압연 공정의 측정값으로 후판 선단부가 얼마나 휘는지 예측하는 과제를 준비했습니다. 학생들은 모델을 돌리기 전에 빠진 값의 분포를 살폈습니다. 범주형 변수를 어떻게 처리할지 정해 그 과정을 노트북과 보고서에 남겼습니다.

채점에서 본 것

데이터 확인, 특성 준비, 모델 결과 해석에 공통 기준을 적용할 수 있도록 채점 가이드를 작성했습니다. 예측값만 보고 채점하면 드러나지 않는 전처리와 분석 판단도 평가했습니다.
