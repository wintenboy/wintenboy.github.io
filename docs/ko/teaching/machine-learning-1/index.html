머신러닝 1 (DSS6003)

2025년 2학기 · 수업 조교, 연세대학교

후판 휨을 예측하는 회귀 과제

압연 공정에서 측정한 변수로 후판 선단의 휨을 예측하는 과제를 준비했습니다. 학생들은 결측치와 범주형 변수를 처리한 뒤 다중선형회귀, Ridge, Lasso를 비교했습니다. 학습과 검증 데이터의 R²와 RMSE를 따로 보고하고 규제 모델은 교차검증으로 확인하도록 했습니다.

노트북의 분석 과정도 봤습니다

실행 결과가 담긴 노트북과 그 결과를 해석한 보고서를 받았습니다. 예측 결과와 함께 데이터 확인, 전처리, 모델 비교 과정도 볼 수 있도록 채점 기준을 정리했습니다.
