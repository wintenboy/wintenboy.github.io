머신러닝 1 (DSS6003)

2025년 2학기 · 수업 조교, 연세대학교

후판 휨 회귀 과제

압연 공정의 측정값으로 후판 선단의 휨을 예측하는 과제를 준비했습니다. 과제에서는 결측치와 범주형 변수를 처리한 뒤 다중선형회귀, Ridge, Lasso를 비교하도록 했습니다. 학습·검증 데이터의 R²와 RMSE를 따로 보고하고 규제 모델을 교차검증하도록 안내했습니다.

채점

노트북과 보고서를 함께 보며 학생이 데이터를 어떻게 정리하고 모델을 비교했는지 확인했습니다.
