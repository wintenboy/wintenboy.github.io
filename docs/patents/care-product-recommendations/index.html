Care product recommendation system to improve nursing service quality

2023 · Published application · KR 10-2023-0185772 · Co-inventor

Application record

Product similarity and the care setting

The application uses a multimodal model trained with structured patient data and text from consultations and product reviews. The system checks product similarity, then checks whether the shortlisted products fit the care setting.
