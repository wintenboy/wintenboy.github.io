Method for assisting marketers in data analysis and electronic device for performing the same

2026 · Granted patent · KR 10-2972642 · Co-inventor

Patent record

From blog and purchase reviews to a query

The patented method prepares blog reviews and purchase reviews in a common database. A marketer can ask a question in ordinary language. The analysis interface uses that request to select a method and run it against the review data. The patent describes examples such as extracting keywords or plotting the distribution of star ratings.

Inventors

The grant lists Jaeyeon Jang, Geon Woo Kim, Hyeoni Kim, Chae Won Yun, and Seungyeol Ryu.
