Method for assisting marketers in data analysis and electronic device for performing the same

2026 · Granted patent · KR 10-2972642 · Co-inventor

Patent record

Review data behind the chat

The patent covers preparing blog reviews and purchase reviews in a common database. The analysis module reads a marketer’s question, then selects and runs an analysis. Examples include extracting keywords and plotting the distribution of star ratings.

Inventors

Jaeyeon Jang, Geon Woo Kim, Hyeoni Kim, Chae Won Yun, and Seungyeol Ryu.
