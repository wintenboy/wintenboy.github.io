The analysis task

The granted patent addresses how marketers can ask questions about customer reviews in ordinary language. The system gathers blog reviews and purchase reviews, prepares those records, and builds a database that a conversational analysis interface can query.

My role

I am listed as a co-inventor with Jaeyeon Jang, Geon Woo Kim, Hyeoni Kim, and Chae Won Yun. The patent record contains the claims and identifies the inventors.
