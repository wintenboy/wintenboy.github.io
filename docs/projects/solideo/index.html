AI assistant for municipal services

Mar 2026–present · Project manager, Solideo

Routing a request

I coordinated the prototype team, managed the schedule, and worked on the workflow and database design. When a request is missing information, the chat asks a follow-up. The regulation search agent uses vector search and graph traversal. A separate agent handles forms.

Reviewing a form

The prototype routes the form to a person for review. The memory agent carries the original request forward when the user answers a follow-up. We submitted the prototype to a public-service innovation competition.
