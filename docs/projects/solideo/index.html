AI assistance for local government administration

Mar 2026–present · Project manager, Solideo

I managed the AI assistant prototype. I worked on the conversation flow so it could ask for missing details, retrieve the relevant public-service guidance, and use those sources to draft an answer.

What I was responsible for

I managed the prototype schedule and team as project manager. I led decisions on the multi-agent workflow and database design, including how the conversation should ask for missing details and when it should hand a request to a different agent.

From a question to a supported answer

The design separates input checks and intent routing from retrieval. The retrieval agent searches legal text with vector and graph search. A separate agent handles forms, with human review before a submission step. The memory agent keeps the context needed to continue a conversation without sending the full history every time.

What the team delivered

We assembled a prototype and documented the architecture for the public-service innovation competition. The PowerPoint figure shows how the chat interface, orchestrator, legal sources, and form-related functions fit together.
