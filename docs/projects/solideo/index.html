AI assistance for local government administration

Mar 2026–present · Project manager, Solideo

Follow-up questions and agent routing

As project manager I coordinated the team and schedule. I also worked on the database and the workflow that decides when to ask a follow-up question and which agent should handle the request. The legal search agent combines vector search with graph traversal. A separate agent handles forms.

Form review

The prototype includes a human review step for form handling. The memory agent keeps the details the next turn needs, so the user can answer a follow-up without repeating the whole request. We submitted the prototype for a public-service innovation competition.
