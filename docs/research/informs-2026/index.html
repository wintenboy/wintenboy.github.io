Adaptive Model Selection for Time-Series Classification with Language Model

2026 · INFORMS Annual Meeting · San Francisco, CA, November 2026 · Presenter

We used a language model to choose which classifier to apply to each time series.

Conference information

The choice to make

A single classifier chosen for an entire time-series dataset can miss examples that another model handles better. At the INFORMS Annual Meeting I presented a router that picks one pre-trained classifier for each input, then leaves the final class prediction to that classifier.

What the router sees

We combined dataset metadata, discrete time-series tokens, and a natural-language description. The language model uses those representations to choose from the candidate models. It predicts a model choice rather than generating the final class label.

Training and comparison

We trained the router using Partial Cross-Entropy and Reinforcement Learning from Calibrated Decision. In the presentation I compared input-level routing with picking one best model per dataset on 18 selected UCR 2019 datasets. The comparison was about when model selection at the input level was useful.
