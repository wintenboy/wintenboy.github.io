Adaptive Model Selection for Time-Series Classification with Language Model

2026 · INFORMS Annual Meeting · San Francisco, CA, November 2026 · Presenter

The classifier with the best average accuracy on a dataset can still be a poor choice for an individual time series.

Conference information

One classifier per time series

At INFORMS I presented a way to choose among pre-trained classifiers for each input. The language model reads dataset metadata, tokens derived from the series, and a short text description. It returns the name of a classifier. We then run that classifier on the series to get the class prediction.

Several classifiers can get the same input right

We trained the router with Partial Cross-Entropy and Reinforcement Learning from Calibrated Decision. More than one candidate can classify a training example correctly. The selection problem is therefore to learn which candidates can handle that example. In the talk I compared per-input routing with choosing one best classifier for the entire dataset, using 18 datasets from the UCR 2019 archive.
