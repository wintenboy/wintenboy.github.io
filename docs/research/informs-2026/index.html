Adaptive Model Selection for Time-Series Classification with Language Model

2026 · INFORMS Annual Meeting · November, San Francisco, CA · Presenter

Conference information

Picking a classifier for each input

A classifier can rank first on a dataset and still miss a series that another model gets right. The router reads dataset metadata, tokens made from the series, and a text description. It picks a pre-trained classifier, which then predicts the class.

Training the router

Several classifiers can get the same example right. We used Partial Cross-Entropy and Reinforcement Learning from Calibrated Decision to train the router on those examples. At INFORMS I compared this with running one classifier per dataset across 18 UCR 2019 datasets.
