Machine Learning 1 (DSS6003)

Fall 2025 · Teaching assistant, Yonsei University

Steel plate data for a regression assignment

I helped prepare a regression assignment using rolling-process measurements and plate-tip warping as the target. The handout asked students to identify missing values and categorical fields, then fit multiple linear regression, Ridge, and Lasso. They reported R² and RMSE separately for training and validation and cross-validated a regularized model.

Notebook and report

Students submitted the notebook with its outputs and a report based on those results. I worked with the grading guide so the data checks and model comparisons could be assessed alongside the predictions.
