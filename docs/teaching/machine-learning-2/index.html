Machine Learning 2 (DSS6017)

Spring 2025 · Teaching assistant, Yonsei University

Course support

I supported the second machine learning course in the DSS program, which covered subjects including support vector machines, ensembles, dimensionality reduction, and clustering. My work included preparing practice materials and helping students connect the methods with the assignments.

Assignment data and grading

For the assignments, I worked on training and test splits, submission examples, and grading materials. The examples gave students one prediction format to follow and made it possible to evaluate submissions on the same held-out data.
